# Implementation Plan: Entity Layering Control

**Branch**: `023-entity-layering` | **Date**: 2026-05-16 | **Spec**: `specs/023-entity-layering/spec.md`

## Summary

Add per-entity `zIndexOffset` to control rendering order within type groups, plus "Bring Forward" / "Send Backward" context-menu actions. The type hierarchy (cone/equipment < player < ball) is already implemented in `EntityLayer.tsx` — this plan extends it with intra-type user control and persistence.

## Implementation Sequence

### Phase A — Core types (no UI, no store)

**Files**: `src/core/types/index.ts`

1. Add `zIndexOffset?: number` to `Entity` interface (after `orientation?`)
2. Add `zIndexOffset?: number` to `EntityUpdate` interface

No logic changes — type definitions only. TypeScript compiler will flag any incomplete spreads.

---

### Phase B — Store action

**Files**: `src/core/stores/projectStore.ts`

1. Add `updateEntityLayerOffset` to the store interface:

   ```typescript
   updateEntityLayerOffset: (entityId: string, zIndexOffset: number) => void;
   ```

2. Implement: iterate all frames, update `zIndexOffset` on the matching entity in each frame, set `isDirty: true`.

3. Extract a pure helper function `computeLayerSwap`:

   ```typescript
   export function computeLayerSwap(
     entities: Entity[],
     entityId: string,
     direction: 'forward' | 'backward'
   ): Array<{ id: string; zIndexOffset: number }> | null
   ```

   **Algorithm**:
   - Sort `entities` by `(zIndexOffset ?? 0)` ASC, then `id` ASC (tiebreaker)
   - Find entity at `entityId` → rank R
   - `'forward'`: swap with rank R+1 entity; return null if R is already last
   - `'backward'`: swap with rank R-1 entity; return null if R is already first
   - Returns array of `{ id, newOffset }` pairs (2 items on success)

4. Write unit tests for `computeLayerSwap` (pure function, no store needed).

---

### Phase C — EntityLayer sort

**Files**: `src/features/animation/components/Canvas/EntityLayer.tsx`

Replace the existing 1-key sort:

```typescript
// Before
const sorted = [...interpolatedEntities].sort(
    (a, b) => (LAYER_ORDER[a.type] ?? 2) - (LAYER_ORDER[b.type] ?? 2)
);

// After
const sorted = [...interpolatedEntities].sort((a, b) => {
    const tierDiff = (LAYER_ORDER[a.type] ?? 2) - (LAYER_ORDER[b.type] ?? 2);
    if (tierDiff !== 0) return tierDiff;
    const zDiff = (a.zIndexOffset ?? 0) - (b.zIndexOffset ?? 0);
    if (zDiff !== 0) return zDiff;
    return a.id.localeCompare(b.id);
});
```

This is the only change in `EntityLayer.tsx`. Replay and share views use the same component and inherit the fix.

### Phase F — Context menu handlers

**Files**: `src/features/animation/components/hooks/useEditorContextMenuHandlers.ts`

1. Import `computeLayerSwap` from the store utility.

2. Add two new derived flags computed when `contextMenu` is not null:
   ```typescript
   const contextMenuCanBringForward: boolean = ...
   const contextMenuCanSendBackward: boolean = ...
   ```
   Computation:
   - Get all entities of same type as `contextMenu.entityId` in current frame
   - Sort by `(zIndexOffset ?? 0)` ASC then `id` ASC
   - Rank R = index of `contextMenu.entityId` in this list
   - `canBringForward = R < list.length - 1`
   - `canSendBackward = R > 0`
   - Both false when `list.length <= 1`

3. Add `handleContextMenuBringForward`:
   - Call `computeLayerSwap(sameTypeEntities, entityId, 'forward')`
   - For each `{ id, zIndexOffset }` pair, call `updateEntityLayerOffset(id, zIndexOffset)`

4. Add `handleContextMenuSendBackward` (same with `'backward'`).

5. Return the new handlers and flags from the hook.
