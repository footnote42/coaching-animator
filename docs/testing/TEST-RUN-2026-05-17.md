## Notes

- localhost:3000 had a ChunkLoadError on `/app` (stale build). All tests run against **localhost:3001** (freshly started server).
- Save modal field is "Coaching Notes" (not "Coaching Points" as named in test script) — same field, different label.
- T-021: Only Google OAuth available. Spec allows Apple and GitHub but neither is implemented.
- T-026: No success toast on profile save — update is immediate/inline. Consider adding toast for confirmation.
- T-061: Pressing Enter in Tags field submits the save form — coaching notes were not persisted because the form submitted before the user had a chance to save. This caused T-083 to be untestable.
- T-052: Tested via "Send Backward" on top entity (equivalent to "Bring Forward" on bottom entity) since bottom entity was inaccessible via right-click when stacked.
- T-074: The toolbar "Share Animation" button is correctly disabled for unsaved animations. Only the sidebar "Share Link" path bypasses the guard.
- T-094: Add Progression on "T-061 Test Drill (edited)" (animation ID `a709b2a5-7d1e-4e11-bf18-8dd9718a8362`) produces `parentId` that causes "Failed to load project" schema validation error. Tested successfully on "T-061 Test Drill" (ID `23b63f61-a643-450b-8784-04caa50e2d2d`) instead.
- T-111: "Test123 — Progression NaN" title in progression navigation is pre-existing data created before the progressions NaN fix (commit `27139ee`) was applied — not a regression.
