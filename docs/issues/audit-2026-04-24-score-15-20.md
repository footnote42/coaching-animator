## P1 Issues — Major (Fix Before Release)

### 1. Rounded corners violate zero-radius token (15+ occurrences)
- **Files**: `src/app/profile/page.tsx`, `src/app/admin/page.tsx`
- **Issue**: Design token `--border-radius: 0px` is explicit and deliberate (coaching whiteboard aesthetic). Card shells are now correctly zero-radius, but every form input, button, and alert box inside them still has `rounded-lg`, `rounded-md`, or bare `rounded`.
- **Lines**: profile.tsx lines 254, 260, 274, 290, 311, 339, 348, 372, 452, 504, 515; admin.tsx lines 153, 258, 265, 445, 586, 595
- **Impact**: Visual inconsistency. The page shifts register mid-screen — raw card shells containing soft inputs. Contradicts the deliberate utilitarian aesthetic.
- **Fix**: Remove all `rounded-*` classes from form elements. Use `/shape` command.

### 2. `bg-white` in editor-layer and shared components (8 instances)
- **Files**: 
  - `src/features/animation/components/ShareViewer.tsx:161`
  - `src/features/animation/components/Editor.tsx:687, 804`
  - `src/features/animation/components/ReplayViewer.tsx:178`
  - `src/shared/ui/ConfirmDialog.tsx:38`
  - `src/shared/ui/EntityContextMenu.tsx:64`
  - `src/features/animation/components/Canvas/InlineEditor.tsx:73`
  - `src/features/animation/components/Sidebar/SportSelector.tsx:33`
- **Issue**: Off-token white surfaces in components used across the app. If palette ever shifts away from white-friendly backgrounds, these break.
- **Impact**: Token system violation; brittleness under future design changes.
- **Fix**: Replace with `bg-surface`. Use `/colorize` command.

### 3. `bg-gray-*` residual in editor timeline and dialog
- **Files**: 
  - `src/features/animation/components/Timeline/FrameStrip.tsx:59` — `bg-gray-100 text-gray-400`
  - `src/shared/ui/ConfirmDialog.tsx:40-41` — `text-gray-500`
- **Issue**: Unresolved grays in components that appear throughout the app (FrameStrip in every animation; ConfirmDialog in modals).
- **Impact**: Inconsistent disabled/secondary states.
- **Fix**: `bg-gray-100` → `bg-surface-warm`, `text-gray-*` → `text-text-primary/[40|60]`. Use `/colorize`.

### 4. Auth page headings missing `font-heading` (5 instances)
- **Files**:
  - `src/app/(auth)/login/page.tsx:68` — `<h2 className="text-xl font-semibold ...">Sign In</h2>`
  - `src/app/(auth)/register/page.tsx:90`
  - `src/app/(auth)/forgot-password/page.tsx:35`
  - `src/app/(auth)/reset-password/page.tsx:73, 101`
- **Issue**: Auth pages are high-traffic (every new user). Headings render in Inter body instead of Oswald, breaking the typographic system at a critical conversion funnel.
- **Impact**: Typographic inconsistency at a high-visibility location.
- **Fix**: Add `font-heading` to each `<h2>`. Use `/typeset`.

## P2 Issues — Minor (Fix in Next Pass)

### 1. Gallery search/filter: weak keyboard focus indicator
- **File**: `src/app/gallery/GalleryClient.tsx:257, 268`
- **Issue**: `focus:outline-none focus:border-primary` — keyboard users get only a border colour change as a focus indicator. On the cream/warm palette, this colour contrast may be < 3:1 (WCAG 2.1 SC 1.4.11).
- **Fix**: Remove `focus:outline-none` or add explicit `focus-visible:ring-2 focus-visible:ring-primary`. Use `/harden`.

### 2. Admin spinners missing `role="status"`
- **File**: `src/app/admin/page.tsx:165, 464`
- **Issue**: Loading state not communicated to screen readers.
- **Fix**: Add `role="status" aria-label="Loading"` to spinner divs. Use `/harden`.

### 3. `bg-black/50` modal overlays — pure black banned
- **Files**: 
  - `src/app/admin/page.tsx:249, 572`
  - `src/shared/components/ReportModal.tsx:67`
  - `src/shared/components/EditMetadataModal.tsx:75`
  - `src/shared/components/SaveToCloudModal.tsx:163`
  - `src/shared/components/DeleteConfirmDialog.tsx:22`
  - `src/shared/components/OnboardingTutorial.tsx:60`
  - `src/shared/ui/dialog.tsx:24` (80% opacity)
- **Issue**: Pure black (#000) is explicitly banned in the design principles. Should be a tinted scrim using the brand green.
- **Fix**: `bg-black/50` → `bg-primary/60` (or `bg-primary/40` depending on desired darkness). Use `/colorize`.

### 4. Template badge + remix button use off-token blue
- **File**: `src/features/gallery/components/PublicAnimationCard.tsx:145, 267`
- **Issue**: 
  - Line 145: `bg-blue-600/90 text-white` (Template badge)
  - Line 267: `bg-blue-600 hover:bg-blue-700` (Remix button)
- **Impact**: Arbitrary blue on gallery cards breaks colour cohesion.
- **Fix**: Replace with `bg-primary` and `hover:bg-primary/90`. Use `/colorize`.

### 5. Progress bar animates layout property
- **File**: `src/app/profile/page.tsx:428`
- **Issue**: `transition-all` with dynamic `width` value animates a layout property, triggering layout recalculation on each animation frame.
- **Fix**: Use `transition-[width]` instead of `transition-all`. Use `/optimize`.

## P3 Issues — Polish (Nice-to-Fix)

### 1. Inter body font — monoculture default
- **File**: `src/app/globals.css:18` — `--font-body: 'Inter', system-ui, sans-serif`
- **Status**: Documented gap in `.impeccable.md`
- **Issue**: Inter is the most overused web font and appears in the explicit reject list. For outdoor mobile use (the stated use-case), a font with stronger stroke contrast (Barlow, Overpass, Chivo) would serve legibility better.
- **Effort**: High — affects every page. Flag for dedicated `/typeset` pass.

### 2. Admin search input fixed width
- **File**: `src/app/admin/page.tsx:153` — `w-56`
- **Issue**: At very narrow viewports (< 375px), can compete for space.
- **Fix**: `w-56` → `w-full sm:w-56`. Use `/adapt`.

### 3. Auth Google button bare `rounded`
- **Files**: `src/app/(auth)/login/page.tsx:136`, `register/page.tsx:212`
- **Issue**: Bare `rounded` class may not reliably pick up the `--border-radius: 0px` token in Tailwind v4.
- **Fix**: Remove `rounded`. Use `/shape`.

### 4. Semantic color alerts in profile/admin
- **Files**: profile/admin pages use `bg-green-50 border-green-200 text-green-600`, `bg-red-50` for success/error states
- **Note**: These are functional semantic colors (not brand colors) and are acceptable. But consider standardizing to `bg-surface-warm border-border text-primary/80` for visual consistency. Low priority.
