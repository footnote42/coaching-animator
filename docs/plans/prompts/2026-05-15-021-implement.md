## Key implementation decisions (from plan.md)

1. **TimelinePanel reads from stores** — no props. Use `useProjectStore` and `useUIStore` directly (same pattern as EditorFloatingRemote)
2. **Visibility gate**: `{!focusMode && !isMobile && <TimelinePanel />}` — hidden in focus mode (consistent with left sidebar)
3. **Layout**: Right-side sibling in the `flex h-screen` container, `w-64`, `bg-tactics-white border-l border-border`
4. **FrameStrip inside panel**: Import existing `FrameStrip` from `src/features/animation/components/Timeline/`; wrap in `overflow-y-auto flex-1`
5. **Delete Frame guard**: Disabled when `totalFrames === 1` (`opacity-50 cursor-not-allowed`)
6. **CRITICAL — Two remotes**: Only `EditorFloatingRemote` is deleted. `FloatingRemote` in `ShareViewer.tsx` is untouched
7. **Footer removed**: The `<footer>` block in Editor.tsx (`PlaybackControls` + `FrameStrip`) is replaced by TimelinePanel
8. **localStorage keys** `editor-remote-pos` and `editor-remote-expanded` are abandoned — no migration needed
9. **Design tokens**: `rounded-none`, no `shadow-*`, `bg-tactics-white`, `border-border` — matches left sidebar treatment
